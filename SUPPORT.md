# Support

## Documentation and community questions

Start with the README, examples, release notes, and troubleshooting information in the relevant repository. For reproducible software bugs or focused technical questions, use that repository's GitHub Issues page.

When requesting help, include the repository version or commit, environment details, expected behavior, actual behavior, and a minimal reproduction. Remove credentials, private network information, and personal or proprietary data from logs and screenshots.

## Product and technical support

- Technical support: [support@mirrormetech.com](mailto:support@mirrormetech.com)
- Education and university collaboration: [education@mirrormetech.com](mailto:education@mirrormetech.com)
- Purchasing and partnerships: [partner@mirrormetech.com](mailto:partner@mirrormetech.com)
- Website: [mirrormetech.com](https://www.mirrormetech.com/cn/)

GitHub Issues are public and are not suitable for account information, private robot data, security vulnerabilities, or urgent hardware assistance.

## Security and safety

Report vulnerabilities privately by following the [Security Policy](https://github.com/mirrormerobotics/.github/security/policy). If a robot behaves unexpectedly, stop operation and follow the product's documented shutdown and safety procedures before troubleshooting.
